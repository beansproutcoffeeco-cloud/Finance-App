# 📖 How to Use This Tracker

Start here. This page explains every section of the workspace, every
abbreviation used in the program, and the exact process for a training day.

## What's in this workspace

| Section | What it is | When you use it |
|---|---|---|
| **Sessions** | One page per workout (53 total), with the full gym AND home prescriptions in the page body | Every training day |
| **Set Log** | One row per set. Pre-filled with every planned gym set — you just add weight/reps and check **Done** | During the workout |
| **Exercise Library** | Every movement: why it matters for riding, how to do it, mistakes, easier/harder versions, home swap | When form feels off or you need a substitute |
| **Charts** (views on Sessions & Set Log) | Weekly Volume, Weekly Jump Contacts, e1RM Trend | Weekly check-in |

## A training day, start to finish

1. **Open today's session** — Sessions → **Up Next** view (today is the top row), or the Calendar view, or the link inside the Google Calendar event.
2. **Pick your variant** — set **Location** to Gym or Home. The page body shows both prescriptions; do the one matching your location.
3. **Warm up** — the warmup list is at the top of each variant section.
4. **Work through the exercise bullets in order.** Rest times and tempos are on every line (how to read them is explained below).
5. **Log as you go** — open the session's **Set Log** relation. Every planned gym set already exists as a row like `goblet squat — set 1/3 (8-10)`. Tap the row → enter **Weight** and **Reps** → tick **Done**. Holds and jumps: tick **Done** (put hold-seconds in Reps if you want the record).
6. **Cool down**, then on the session page set **Status = Done**, fill **Duration (min)** and **Session RPE** (how hard the whole session felt, 1–10).

Total logging overhead: about 2–3 minutes per session.

## How to read a prescription line

`goblet squat — 3×8-10 @RPE 7, tempo 3-1-1, rest 120 s — notes`

- **3×8-10** — 3 sets of 8 to 10 reps. Start at 8; when all sets hit 10, add weight next time (see Progression below).
- **8/leg, 10/side, 30 s/side** — do that amount on EACH leg/side.
- **@RPE 7** — target effort (see RPE in the glossary).
- **tempo 3-1-1** — seconds for each phase: 3 s lowering, 1 s pause, 1 s up. `3-0-3` = 3 s down, no pause, 3 s up. `iso` = hold still.
- **rest 120 s** — rest after each set before the next.
- **[superset S1]** — the two lines tagged S1 alternate: do a set of the first, 15 s, a set of the second, then rest and repeat.
- **[contrast C1]** — heavy set first, rest ~30 s, then the paired explosive jumps, then the long rest. The heavy set "wakes up" the nervous system so the jumps are sharper.
- **Circuit sessions (Saturdays)** — the header says e.g. `Circuit: 3 rounds, 90 s between rounds, 15 s between stations`. Do the stations top to bottom with 15 s between them; that's one round. Rest 90 s, repeat.
- **Aerobic finisher** — the last line on Saturdays. `Zone 2` = conversational pace; intervals list hard/easy minutes.

## Glossary — every abbreviation in this workspace

| Term | Meaning |
|---|---|
| **W01 D1** | Week 1, Day 1. D1 = Monday, D2 = Wednesday, D3 = Saturday |
| **A / B / C** | The three session types. A = Lower Strength + Core (Mon), B = Power + Balance (Wed), C = Quad Endurance + Aerobic (Sat) |
| **Block 1–5** | Training phases: 1 Base (W1-4), 2 Strength (W5-8), 3 Strength→Power (W9-12), 4 Power + quad-endurance peak (W13-16), 5 Taper (W17-18) |
| **RPE** | Rating of Perceived Exertion, 1–10. RPE 7 = could do 3 more reps. RPE 8 = 2 more. RPE 6 = deliberately easy. Never grind to 10 in this program |
| **Deload** | Weeks 4/8/12/16: ~40% less volume, same weights. Recovery is where adaptation happens — don't add extra work |
| **Tempo (3-1-1)** | Seconds per phase: lowering-pause-lifting. Slow lowering = eccentric emphasis, the #1 quality for absorbing terrain |
| **iso** | Isometric — hold the position without moving (wall sit, split-squat hold) |
| **e1RM** | Estimated one-rep max, computed as weight × (1 + reps/30). Tracks strength without ever testing a true max |
| **PR** | Personal record — heaviest weight you've logged for that exercise |
| **Zone 2 / Z2** | Easy aerobic pace — you could hold a conversation. Builds the engine for full riding days at altitude |
| **Jump contacts** | Number of landings in a session. Capped and ramped deliberately (55→131/week) because tendons adapt slower than muscles |
| **DB / BB** | Dumbbell / Barbell |
| **RDL** | Romanian Deadlift — hip-hinge with a flat back, soft knees |
| **SL** | Single-leg |
| **MB / med ball** | Medicine ball |
| **Superset** | Two exercises alternated to save time, sharing the rest period |
| **Contrast pair** | Heavy strength set followed by explosive jumps — power development |
| **Spanish squat** | Squat with a band anchored behind the knees — big quad work, minimal knee stress |
| **Snap-down** | Landing drill from standing — the home swap for box drops |
| **Sets Done** (session) | How many Set Log rows you've ticked Done for that session — only checked rows count |
| **Session Volume** | Sum of weight × reps across the session's logged sets |
| **Last Logged** (exercise) | When you last completed a set of it. Shows a 1969/1970 date until the first set is checked Done — that's the "never logged yet" placeholder |
| **Done / Done At** | The checkbox that marks a set complete, and the timestamp behind it. Pre-filled rows don't count anywhere until Done is ticked |

## How progression works (the whole system in one paragraph)

**Double progression.** Every strength exercise has a rep range (e.g. 3×8–10).
Week 1, find a weight that leaves ~3 reps in the tank. Keep that weight until
**all sets hit the top of the range** at target RPE — then add **+5 lb** (lower
body) / **+2.5 lb** (upper body) next time. Where load can't move (holds,
jumps, bodyweight): +5 s hold, +1 rep, or the program ramps it for you. To see
where you stand, check the exercise's page: **PR Weight**, **Best e1RM**,
**Last Logged**, and its recent Set Log rows (your last weights).

- **Missed a session?** Skip it. Mark Status = Skipped and do the next one as
  scheduled. Never shift dates. Missed 2+ in a week → repeat that week's
  weights next week instead of progressing.
- **Feeling wrecked?** Do the session at RPE 6 (~10% lighter). It doesn't
  count toward progression decisions.
- **Traveling?** Do the home variants. Holds, tempo work and jumps progress as
  scheduled; barbell lifts resume at last gym weight (90% after 3+ weeks away).

## Gym vs home

Every session page has both versions — same purpose, same intensity, adjusted
volume/tempo for lighter equipment. The pre-filled Set Log rows assume the
**gym** version. On a home day: set Location = Home, follow the Home section,
and either edit the seeded rows (repoint Exercise where the movement differs,
e.g. snap-down instead of box drop) or add fresh rows from the session's Set
Log relation — the session link fills itself. A whole week at home still
counts and still progresses.

## Weekly check-in (2 minutes, e.g. Sunday)

1. **Weekly Volume** chart — is it climbing gently, dipping on deload weeks?
2. **Weekly Jump Contacts** chart — should follow the planned ramp.
3. **e1RM Trend** (Sessions) — best estimated 1RM per program week; the line
   should drift up. **Best e1RM by Exercise** (Set Log) shows strongest lift
   per movement.
4. Any knee pain during step-ups, Spanish squats, or split-squat holds that
   isn't going away → book a physio before the jump-heavy blocks (week 9+).
   Reduce depth or swap to extra wall-sit time in the meantime.

## Housekeeping

- Seeded rows for sessions you skipped just stay empty — they don't affect any
  totals (only **Done** rows count). Delete them if you like tidy.
- Leave a seeded row's title alone; it carries the target (sets × reps).
- The source of truth lives in the git repo (`training/program.json`). To
  change the plan, edit + regenerate there and re-push — see the repo README.
